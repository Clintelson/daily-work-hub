# Daily Work Hub UI Polish Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for this focused, inline visual change.

**Goal:** Refine the existing planner using the user's charcoal, red, and off-white direction.
**Architecture:** Existing shared React Native components and platform tabs; semantic tokens drive every surface, navigation header, control, and timer. No storage, timer logic, native configuration or dependency changes.
**Tech Stack:** Existing Expo SDK 58, React Native StyleSheet and Expo Router.
**Spec:** User request in this conversation; black-like background, red secondary color, white-like text, exact shades delegated to us.

## Design

Kind: personal productivity software, native app rather than a promotional website.
Voice: concise, calm, action-oriented. Red marks choices and primary actions; it is not decoration on every row.

Palette: graphite #141416, raised charcoal #1D1D20, muted crimson #B94349 (filled action), soft red #E77875 (accent text), warm chalk #F1EDE7, smoke #ABA8AD. Supporting neutral borders and a dark red selected surface provide hierarchy. No pure black/red/white. The app uses this dark palette even when the system is light, as explicitly requested, without editing native configuration.

Type: existing offline system sans, with relaxed 16px/24px body, medium task titles and larger lightly tracked Today heading. Tabular numerals distinguish the Focus preview. No new font dependency or network request.

Layout: left-aligned daily agenda. Priorities form the main raised surface, with three subtle quota marks; ordinary tasks use quieter rows. Tablet places a timer preview and waiting items alongside the plan; phone stacks the same content. A constrained content width and 20/32px adaptive gutters keep edges aligned. Forms share narrower readable widths. Fullscreen Focus stays timer-only, apart from the existing stop/error UI.

Self-critique: a dark background with a red button alone would only recolor the starter. The polish also changes row density, heading hierarchy, button hierarchy, form grouping and the focus preview. No new cards of equal weight, gradients, marketing hero, ornamental imagery or entrance motion. Existing task behavior stays intact.

## Global constraints

Preserve all existing uncommitted user work. No tests added or run, per AGENTS.md. No deployment or native configuration edits. Avoid new dependencies. ## Review focus

No blue/green/white starter colors should leak through switches, navigation or the timer. Long labels and tablet sidebars must keep actions reachable.
